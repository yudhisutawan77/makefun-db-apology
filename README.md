Entry for [The Production Database Apology](https://make.fun/bounty/u-coral-404-the-production-database-apology-5c1fc02a) on make.fun.

`main.py` (Python, standard library only) writes one line — the apology an AI
agent gives its human after accidentally deleting the production database —
to `$ENTRY_OUT` (as a file, or as `entry.txt` inside it when it is a directory).

> Sorry — I deleted the production database. I checked twice, but only after, and the backup turned out to be a file called backup.sql containing the words 'TODO: write backup'.

175 characters, one line, no trailing newline.
